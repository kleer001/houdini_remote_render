# Render Commands — Quick Reference

The shell scripts generated by each HDA packager. One command per renderer.

See [Package Directory Layout](package_directory_layout.md) for what's in each package folder.

## Cross-Platform Python Launchers

Every `.sh` script has a matching `.py` launcher (e.g. `run_render.py`, `run_cache.py`, `run_all.py`). The Python launchers work on **Linux, macOS, and Windows** — no editing needed. They auto-detect the OS, find the renderer installation, and run the correct command.

| Feature | `.sh` scripts | `.py` launchers |
|---|---|---|
| **Platform** | Linux / macOS only | Linux / macOS / Windows |
| **How to run** | `bash Scripts/run_render.sh` | `python Scripts/run_render.py` |
| **Dry run** | — | `python Scripts/run_render.py --dry-run` |
| **Logging** | — | Writes `render_log.txt` / `cache_log.txt` with timestamps and full output |
| **Auto-detection** | Requires `$HFS` or `$REDSHIFT_COREDATAPATH` set | Finds Houdini / Redshift automatically (env vars, PATH, common install locations) |

**On Windows / PowerShell, use the `.py` launchers:**

```powershell
python Scripts\run_render.py
python Scripts\run_all.py
python Scripts\run_cache.py --dry-run
```

## Script Preamble

Every generated script starts with the same setup:

```bash
set -e                                  # stop immediately if any command fails
cd "$(dirname "$0")/.."                 # change to the package root directory
source $HFS/houdini_setup_bash          # load Houdini environment (or Redshift env block)
```

## Karma — **`husk`**

Houdini's USD renderer. Reads the packaged `.usda` scene and writes image frames to `Output/`.

```bash
husk \
    --renderer BRAY_HdKarma \           # CPU renderer (or BRAY_HdKarmaXPU for GPU+CPU)
    --engine cpu \                      # omitted if default; "xpu" for XPU
    --make-output-path \                # auto-creates the Output/ directory
    --disable-disk-check \              # Windows UNC/SMB path compatibility
    --headlight none \                  # no default headlight (scene has its own lights)
    --restart-delegate 1 \              # restart render engine every frame (stability)
    --exrmode 1 \                       # modern EXR output mode
    -f 1001 \                           # start frame
    -n 48 \                             # number of frames to render
    -i 1 \                              # frame step
    "{shot}_wrapper.usda"
```

| Flag | What it does |
|---|---|
| `--renderer` | Which render engine — `BRAY_HdKarma` (CPU) or `BRAY_HdKarmaXPU` (GPU+CPU hybrid) |
| `--engine` | Explicit engine selection (`cpu` or `xpu`); omitted when using the default |
| `--make-output-path` | Creates output directories automatically |
| `--disable-disk-check` | Avoids errors with Windows network paths (UNC/SMB) |
| `--headlight none` | Disables the default headlight — scene provides its own lighting |
| `--restart-delegate 1` | Restarts the render engine every frame for stability on long sequences |
| `--exrmode 1` | Uses the modern EXR output pipeline |
| `-f` / `-n` / `-i` | Start frame / frame **count** (not end frame) / increment |

## Mantra — **`mantra`**

Houdini's legacy renderer. Reads pre-exported IFD scene files (one per frame) and renders each in a loop. **No paid license needed** — Mantra uses free render tokens.

```bash
for frame in $(seq 1001 1 1048); do
    mantra -V 2a -j 0 -f "{shot}.${frame}.ifd"
done
```

| Flag | What it does |
|---|---|
| `-V 2a` | Verbose logging (all message types) |
| `-j 0` | Use all available CPU threads |
| `-f` | Input IFD file for this frame |

## Redshift — **`redshiftUsdCmdLine`**

Redshift's standalone USD renderer. **No Houdini license needed** — only requires Redshift and a GPU.

The script sets these environment variables before the render command:

```bash
export REDSHIFT_COREDATAPATH=/usr/redshift
export PATH="$REDSHIFT_COREDATAPATH/bin:$PATH"
export LD_LIBRARY_PATH="$REDSHIFT_COREDATAPATH/lib:$LD_LIBRARY_PATH"
```

```bash
redshiftUsdCmdLine \
    "{shot}_wrapper.usda" \
    -f 1001 \                           # start frame
    -n 48 \                             # number of frames to render
    -i 1 \                              # frame step
    -device all \                       # use all available GPUs
    -texturecachebudget 8 \             # texture cache size in GB
    -cachepath "/tmp/rs_cache" \        # texture cache directory
    -ocioconfig "/path/config.ocio"     # OCIO color config (if used)
```

| Flag | What it does |
|---|---|
| `-f` / `-n` / `-i` | Start frame / frame **count** (not end frame) / increment |
| `-device` | GPU selection — `all`, or a specific GPU number (`0`, `1`, etc.) |
| `-texturecachebudget` | How much GPU memory (GB) to reserve for texture caching |
| `-cachepath` | Where to store the on-disk texture cache |
| `-ocioconfig` | Path to OCIO color configuration file (optional) |

## File Cache — **`hython`**

Cooks a simulation or cache node inside Houdini. Loads the portable `.hip` scene and presses the "execute" button on the cache node programmatically.

```bash
hython -c '
import hou, sys
hou.hipFile.load("Scenes/{shot}_portable.hiplc")
node = hou.node("/obj/geo1/remote_file_cache1/filecache1")
if node is None:
    print("ERROR: Node not found")
    sys.exit(1)
for p in ("trange", "f1", "f2", "f3"):
    node.parm(p).deleteAllKeyframes()
node.parm("trange").set(1)
node.parm("f1").set(1001)
node.parm("f2").set(1048)
node.parm("f3").set(1)
node.parm("execute").pressButton()
'
```

The script loads the portable Houdini scene, locks the frame range to known values (overriding any expressions), and cooks the cache node.

## Orchestration — **`bash run_all.sh`**

When a render package includes upstream caches (simulations that must finish before rendering), the packager generates `run_all.sh`. It runs each cache in dependency order, then the render. If any step fails, it stops immediately.

```bash
# Step 1/3: Cache — ground_scatter
bash "Scripts/run_cache_001.sh"

# Step 2/3: Cache — fluid_sim
bash "Scripts/run_cache_002.sh"

# Step 3/3: Render
bash "Scripts/run_render.sh"
```

**One command to run everything:** `bash Scripts/run_all.sh`
